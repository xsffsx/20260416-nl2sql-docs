NL2SQL API

Execute one natural-language question against a registered project.

POST /api/nl2sql?projectId=equity
Content-Type: application/json
{
  "query": "What is the total fund count?",
  "recordsLimit": 50
}

projectId is required. Change it to fund or another registered project to run against that project's active runtime. The API does not select a default project.

Response​

{
  "status": "success",
  "confidence": 0.9,
  "query": "What is the total fund count?",
  "queryId": "...",
  "threadId": "...",
  "traceId": "...",
  "sql": "SELECT COUNT(*) ...",
  "results": [{"total": 5}],
  "meta": {},
  "reason": {},
  "suggestedQuestion": [],
  "groundReason": ""
}

The HTTP API and MCP nl2sql tool use the same backend execution flow and active snapshot. The HTTP API does not call the MCP endpoint.

Errors​

  • Missing or unknown projectId: client error; no query starts.
  • Missing or empty query: validation error; no query starts.
  • Runtime readiness or stale active snapshot: explicit readiness error; no fallback configuration is used.
